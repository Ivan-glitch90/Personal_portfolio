# Personal Portfolio

My personal developer portfolio site — built to showcase who I am, my background, and the projects I'm building while learning software development.

## About This Project

I'm transitioning into software development after 10+ years working in hardware and electronics repair (Boeing 737 avionics, iPhones, PCs, gaming consoles). This site is where I'm documenting that journey and putting my projects in one place as I go through the AI Software Development Bootcamp with Circuit Stream.

This is very much a work in progress — I'll keep updating it as I finish new projects and learn more.

## Features

- Responsive navbar with smooth-scroll links to each section
- Hero section introducing my background and current goals
- Projects section (placeholder cards — real projects coming soon as I complete them)
- About section with more detail on my career switch
- Contact section (currently a static form — working on hooking this up to actually send messages)

## Running It Locally

This is a static site, so there's no build step:

1. Clone the repo
   ```bash
   git clone https://github.com/Ivan-glitch90/Personal_portfolio.git
   ```
2. Open `index.html` in your browser (or use a tool like the VS Code "Live Server" extension for auto-reload)
